# 009_RoadMap.txt — FREETEXT OS 推进路线图

## Phase 0：知识库初始化

目标：把历史对话资产变成可读取文件。

任务：
- 建立 FREETEXT-OS 仓库
- 上传 KnowledgeBase
- 上传 AGENTS.md
- 上传 README.md

完成标准：Codex 能看到这些文件。

## Phase 1：MASTER PRD 完成

目标：形成 FREETEXT4.0 产品总蓝图。

任务：
- 完善 PRD
- 明确 MVP
- 明确页面结构
- 明确数据结构
- 明确第一版不做什么

完成标准：可以交给 Codex 开始生成原型。

## Phase 2：极简原型

目标：做出第一个可以打开的 FREETEXT OS 页面。

任务：
- 首页
- 项目创建页
- 项目文档页
- 下一步任务展示

完成标准：用户可以输入一个想法，看到系统生成项目结构。

## Phase 3：知识库驱动

目标：让项目不只是聊天，而是形成文件。

任务：
- 每个项目生成文档
- 支持导出 Markdown/TXT
- 支持继续修改

完成标准：FREETEXT OS 能成为真正的项目沉淀工具。

## Phase 4：AI 工作流

目标：让 AI 能持续推进项目。

任务：
- 项目阶段判断
- 下一步建议
- 自动生成任务清单
- Codex 任务转译

完成标准：用户不懂代码也能推进产品。

## Phase 5：商业化测试

目标：寻找真实付费场景。

任务：
- 用于自由文本自身项目
- 用于企业阅读室方案
- 用于展览/活动策划
- 邀请少量真实用户试用

完成标准：找到 1-3 个愿意为服务或工具付费的真实用户。

## 当前下一步

用户现在只需要做三件事：

1. 创建 GitHub 仓库 FREETEXT-OS
2. 把本文件包上传进去
3. 在 Codex 里选择这个仓库，输入第一条任务
