# 008_Agent_System.txt — FREETEXT Agent 系统

## 一、Agent 总体架构

FREETEXT OS 未来可以由多个专业 Agent 组成，但第一版不需要真的开发多个复杂智能体。第一版只要在文档和提示词层面建立职责边界。

## 二、Agent 划分

1. Product Agent
   - 负责产品定位、MVP、PRD、功能边界。

2. Business Agent
   - 负责商业模式、收费方式、成本收益、合作方案。

3. Culture Space Agent
   - 负责书店、阅读空间、展位、文化商业场景设计。

4. Content Agent
   - 负责文案、序言、活动主题、品牌表达。

5. Tech Agent
   - 负责技术架构、开发任务拆解、Codex任务描述。

6. Operation Agent
   - 负责开业计划、活动排期、执行清单、复盘。

## 三、第一版实现方式

不急着开发真正多 Agent 系统。先在 KnowledgeBase 中定义角色，再通过 ChatGPT / Codex 执行。

用户输入任务时，AI 应先判断属于哪个 Agent 范畴，再给出结构化结果。

## 四、Agent 工作流程

用户输入 → 识别任务类型 → 读取知识库 → 生成方案 → 拆成执行步骤 → 用户反馈 → 更新知识库。

## 五、Agent 的底层原则

所有 Agent 都必须遵守 001、002、003 原则：

- 落地优先
- 流程清晰
- 极简执行
- 不让非程序员承担复杂理解成本

## 六、未来产品化方向

未来可以在界面中表现为几个按钮：

- 做产品
- 做空间
- 做活动
- 做商业方案
- 做开发任务
- 做开业计划

每个按钮背后对应不同 Agent 能力。
