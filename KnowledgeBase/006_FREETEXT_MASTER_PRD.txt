# 006_FREETEXT_MASTER_PRD.txt — FREETEXT4.0 MASTER PRD v0.1

## 一、项目名称

FREETEXT OS / FREETEXT4.0

## 二、项目一句话定义

FREETEXT OS 是一个面向文化行业和非程序员创业者的 AI 创意落地操作系统，帮助用户把想法转化为项目文档、执行计划、商业方案和可持续知识库。

## 三、背景

FREETEXT 过去经历过线下阅读空间、文化商业场景和 AI 产品探索。旧版本曾有技术落地尝试，但 FREETEXT4.0 应重新从产品定义出发，把长期对话和经营经验沉淀为系统。

## 四、目标用户

- 文化公司主理人
- 独立书店/阅读空间经营者
- 企业文化负责人
- 商业地产文化运营人员
- 艺术展览/活动策划者
- 非程序员 AI 创业者
- 想把创意项目真正落地的人

## 五、核心问题

这些用户不是没有想法，而是缺少：

- 清晰项目定义
- 可执行路线
- 专业文档
- 技术翻译
- 长期知识库
- AI 陪跑系统

## 六、核心价值

FREETEXT OS 让用户从一句想法进入系统化执行：

一句想法 → 项目定义 → PRD → 执行计划 → 任务清单 → 文档输出 → AI持续陪跑。

## 七、MVP 范围

第一版只做五件事：

1. 创建项目
2. 生成项目基础文档
3. 显示当前阶段和下一步
4. 允许用户继续对话完善项目
5. 形成可下载/可复制的知识库文件

## 八、核心页面

1. 首页
   - 一句话说明产品
   - 一个输入框：你想落地什么项目？

2. 项目页
   - 项目名称
   - 当前阶段
   - 下一步任务
   - 已生成文档

3. 文档页
   - PRD
   - 用户画像
   - 商业模式
   - 执行计划

4. AI 对话页
   - 围绕当前项目继续推进

## 九、技术建议

当前建议先用简单国际化技术栈：

- 前端：Next.js 或 Vite/React
- 托管：Vercel / Cloudflare Pages / Lovable 过渡
- 数据库：Supabase 或轻量本地 JSON 起步
- AI：OpenAI API 或 ChatGPT/Codex 协作
- 仓库：GitHub

第一版可以先从静态知识库 + 简单前端开始，不急着做复杂数据库。

## 十、成功标准

第一阶段成功不是用户量，而是：

- 能把 FREETEXT4.0 的核心知识库建立起来
- 能用 Codex 基于知识库开始工作
- 能生成第一个可访问原型
- 用户不懂代码也能持续推进
