# Content AI Workflow

## Trigger

Use for cultural/arts content, bookstore strategy, PRDs, AI选书官 rules, prompt design, roadmaps, and source-based synthesis.

## Do Not Trigger

Do not use for low-level code changes unless they encode cultural content rules or AI prompt behavior.

## Input

- User goal and audience.
- Available KnowledgeBase/docs/sources.
- Unknowns and assumptions.

## Output

- Clear product/content artifact.
- Source and uncertainty notes.
- Actionable next steps.

## Steps

1. Confirm product goal, reader, and boundary.
2. Read relevant repository source material before writing.
3. Mark missing information as `待补充`.
4. Never invent copyright, provenance, quotes, metadata, author facts, or art-historical claims.
5. Keep outputs simple enough for non-programmers.
6. Tie each recommendation to落地行动.

## Acceptance

- No fabricated sources or cultural facts.
- The artifact can guide a real next action.
- Assumptions and待补充 items are explicit.

## Common Failures

- Writing high-concept content with no execution path.
- Blending AI speculation with factual metadata.
- Losing FREETEXT OS, Bookstore OS, and AI选书官 hierarchy.

This skill supports 001/002/003 and the rule that cultural/source/copyright information cannot be invented.
