# AI选书官静态可点击原型计划 v0.1

> 所属产品：FREETEXT Bookstore OS  
> 所属模块：AI选书官  
> 当前阶段：静态可点击原型计划，不接真实AI接口  
> 上游文档：AI_BOOK_SELECTOR_WORKFLOW_v0.1.md、AI_BOOK_SELECTOR_PAGE_STRUCTURE_v0.1.md、AI_BOOK_SELECTOR_WIREFRAME_v0.1.md  
> 核心原则：AI做苦活，人做判断

## 1. 本文档目标

本文档定义 AI选书官第一版静态可点击原型应该怎么做。

静态可点击原型不是正式产品。

它的目标是：

- 用假数据模拟真实流程。
- 让用户能从首页一路点到最终清单。
- 验证页面路径是否足够简单。
- 验证“AI做苦活，人做判断”的交互是否成立。

第一版不接真实 AI、不接库存、不接采购、不做登录系统。

## 3. 原型范围

### 3.1 要做

第一版静态原型只做 5 个页面：

| 页面编号 | 页面名称 | 作用 |
| --- | --- | --- |
| 01 | 首页 / 本月选书入口 | 开始本月选书 |
| 02 | 候选书生成页 | 模拟 AI 生成候选书 |
| 03 | AI初筛结果页 | 展示模拟的 A/B/C/D 评级 |
| 04 | 人工复核页 | 模拟人工同意、修改、不接受 |
| 05 | 最终清单与规则沉淀页 | 展示最终候选清单与新增规则 |

### 3.2 不做

第一版坚决不做：

- 不接真实 AI 接口。
- 不接库存系统。
- 不接采购系统。
- 不做登录注册。
- 不做多用户协作。
- 不做真实数据库。
- 不做销售预测。
- 不做复杂图书搜索。
- 不做会员推荐。
- 不做支付。

## 4. 原型数据来源

静态原型使用两轮测试里的真实书目作为模拟数据。

建议先使用第2轮书目，因为第2轮包含更多文学样本，更能体现自由文本气质。

### 4.1 模拟数据结构

每本书保留以下字段：

| 字段 | 示例 |
| --- | --- |
| id | 01 |
| title | 永结无情游 |
| author | 周嘉宁 |
| publisher | 人民文学出版社 |
| category | 文学/长篇小说 |
| ai_rating | A |
| ai_reason | 符合自由文本文学气质 |
| ai_risk | 需确认出版时间、库存、定价 |
| shelf_theme | 当代文学 |
| ai_decision | 是 |
| human_decision | 待复核 |

### 4.2 第一版模拟书目数量

静态原型不需要一次展示全部 40 本。

建议第一版使用 8 本模拟书：

| 编号 | 书名 | 等级 | 用途 |
| --- | --- | --- | --- |
| 01 | 永结无情游 | A | 文学重点样本 |
| 02 | 要有光 | A | 文学非虚构样本 |
| 03 | 士变 | A | 思想史样本 |
| 04 | 先秦人的日常时光 | A | 传统文化样本 |
| 05 | 绿色的火焰 | B | 文学补充样本 |
| 06 | 八成可用社会 | B | 社科非虚构样本 |
| 07 | Land | C | 海外文学观察样本 |
| 08 | 低质流量型成长励志新书样本 | D | 反向对照样本 |

## 5. 页面点击路径

最小可点击路径如下：

```text
首页
点击：开始本月选书
↓
候选书生成页
点击：生成候选书
↓
AI初筛结果页
点击：进入人工复核
↓
人工复核页
点击：保存并下一本 / 完成复核
↓
最终清单与规则沉淀页
点击：导出清单 / 开启下一轮
```

第一版只需要这条路径能点通。

## 6. 页面1：首页 / 本月选书入口

### 6.1 页面内容

显示：

- AI选书官标题。
- 当前月份。
- 当前状态。
- 当前规则版本。
- 上次两轮验证结果。
- 一个主按钮：开始本月选书。

### 6.2 按钮行为

| 按钮 | 点击后 |
| --- | --- |
| 开始本月选书 | 跳转到候选书生成页 |
| 查看上次结果 | 第一版可暂不实现，或跳转到最终清单页 |

### 6.3 静态原型状态

默认显示：

```text
当前状态：未开始
规则版本：v0.1
上次结果：两轮判断完全一致
```

## 7. 页面2：候选书生成页

### 7.1 页面内容

显示：

- 候选书数量：20本。
- 样本结构：文学30%-40%、文史哲20%-25%、社科20%-25%、艺术10%-15%、反向样本1-2本。
- 候选来源：出版社新书目录、豆瓣新书速递、当当/京东新书榜、自由文本过去常进出版社、AI观察。
- 本月排除：低质鸡汤、纯流量畅销、应试工具书。

### 7.2 按钮行为

| 按钮 | 点击后 |
| --- | --- |
| 生成候选书 | 跳转到AI初筛结果页 |
| 保存本轮设置 | 第一版可显示“已保存”假状态 |
| 重新生成 | 第一版可暂不实现 |

### 7.3 静态原型状态

点击“生成候选书”后，不需要真实生成。

直接展示已经准备好的 8 本模拟书目。

## 8. 页面3：AI初筛结果页

### 8.1 页面内容

页面分为两栏：

```text
左侧：候选书列表
右侧：单本书详情
```

左侧显示：

- A类：永结无情游、要有光、士变、先秦人的日常时光。
- B类：绿色的火焰、八成可用社会。
- C类：Land。
- D类：低质流量型成长励志新书样本。

右侧显示当前选中书的：

- 书名。
- 作者。
- 出版社。
- 类别。
- AI推荐等级。
- 推荐理由。
- 风险提醒。
- 适合书架。

### 8.2 按钮行为

| 按钮 | 点击后 |
| --- | --- |
| 全部 | 显示全部书 |
| A重点 | 只显示A类 |
| B可选 | 只显示B类 |
| C观察 | 只显示C类 |
| D不推荐 | 只显示D类 |
| 进入人工复核 | 跳转到人工复核页 |

### 8.3 静态原型状态

筛选按钮第一版可以只做视觉状态，不必真实筛选。

最重要的是：点击“进入人工复核”能进入下一页。

## 9. 页面4：人工复核页

### 9.1 页面内容

每次显示一本书。

显示：

- 当前进度：第1/8本。
- 当前书目信息。
- AI判断。
- 人工判断按钮。
- 人工备注框。

### 9.2 按钮行为

| 按钮 | 点击后 |
| --- | --- |
| 同意 | 当前书标记为同意 |
| 修改 | 当前书标记为修改 |
| 不接受 | 当前书标记为不接受 |
| 保存并下一本 | 切换到下一本，第一版可模拟跳转 |
| 完成复核 | 跳转到最终清单与规则沉淀页 |

### 9.3 第一版复核简化

第一版不必真的完成 8 本逐本状态管理。

可以这样做：

- 页面默认显示第1本《永结无情游》。
- 点击“保存并下一本”后，显示第2本《要有光》。
- 点击“完成复核”后，直接进入最终清单页。

这样就能验证核心交互。

## 11. 技术实现建议

第一版静态原型可以采用非常简单的方式：

- 前端页面。
- 本地假数据。
- 固定路由。
- 无后端。
- 无数据库。
- 无登录。
- 无真实AI调用。

### 11.1 最小文件结构建议

```text
src/
├── data/
│   └── mockBooks.ts
├── pages/
│   ├── HomePage.tsx
│   ├── GeneratePage.tsx
│   ├── ResultPage.tsx
│   ├── ReviewPage.tsx
│   └── FinalPage.tsx
├── components/
│   ├── BookList.tsx
│   ├── BookDetail.tsx
│   ├── RatingBadge.tsx
│   └── StepHeader.tsx
└── App.tsx
```

### 11.2 第一版状态管理

不需要复杂状态管理。

可以用：

- React useState。
- 固定 mock 数据。
- 简单页面跳转。

## 12. 验收标准

静态原型完成后，只检查 5 件事：

| 验收项 | 标准 |
| --- | --- |
| 路径是否跑通 | 首页能点到最终清单页 |
| 页面是否极简 | 没有无关功能 |
| AI判断是否清楚 | A/B/C/D、理由、风险同屏可见 |
| 人工复核是否简单 | 同意/修改/不接受足够明显 |
| 结果是否可执行 | 最终候选清单和新增规则能看懂 |
