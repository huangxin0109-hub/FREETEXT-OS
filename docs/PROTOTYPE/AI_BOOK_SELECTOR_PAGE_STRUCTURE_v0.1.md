# AI选书官最小页面结构文档 v0.1

> 所属产品：FREETEXT Bookstore OS  
> 所属模块：AI选书官  
> 当前阶段：页面结构设计，不写代码  
> 核心原则：AI做苦活，人做判断  
> 设计原则：页面极简、路径极短、只服务第一目标

## 1. 本文档目标

本文档定义 AI选书官第一版原型需要哪些页面、每个页面做什么、包含哪些区块、按钮和字段。

第一版不追求完整系统，只验证最小可用路径：

```text
AI生成候选书
↓
AI评级解释
↓
人复核
↓
生成最终候选清单
↓
沉淀规则
```

## 2. 第一版页面总览

第一版最多 5 个页面：

| 页面编号 | 页面名称 | 是否必须 | 核心作用 |
| --- | --- | --- | --- |
| 01 | 本月选书首页 | P0 | 让用户开始本月选书 |
| 02 | 候选书生成页 | P0 | 让 AI 收集并生成候选池 |
| 03 | AI初筛结果页 | P0 | 查看 AI 的 A/B/C/D 分级与理由 |
| 04 | 人工复核页 | P0 | 人确认、修改或否定 AI 判断 |
| 05 | 最终清单与规则沉淀页 | P0 | 输出最终候选书，并沉淀新规则 |

第一版不超过 5 个页面，避免产品路径变复杂。

## 3. 页面1：本月选书首页

### 3.1 页面作用

这是用户进入 AI选书官后的第一个页面。

它只回答一个问题：

> 现在要不要开始本月选书？

### 3.2 页面区块

| 区块 | 内容 |
| --- | --- |
| 本月状态 | 显示当前月份、是否已开始选书、当前进度 |
| 当前规则版本 | 显示当前使用的选书规则版本 |
| 上次结果摘要 | 显示上轮选书数量、准确率、主要新增规则 |
| 开始入口 | 一个明显按钮：开始本月选书 |

### 3.3 核心按钮

| 按钮 | 作用 |
| --- | --- |
| 开始本月选书 | 进入候选书生成页 |
| 查看上次结果 | 查看上一轮候选清单与规则 |

### 3.4 必要字段

| 字段 | 说明 |
| --- | --- |
| 当前月份 | 例如：2026年6月 |
| 当前状态 | 未开始 / 生成中 / 待复核 / 已完成 |
| 当前规则版本 | 例如：v0.1 |
| 上次准确率 | 例如：100% |
| 上次新增规则 | 简要展示 |

### 3.5 第一版不做

- 不做复杂仪表盘。
- 不做多用户入口。
- 不做社区内容。
- 不做营销首页。

## 4. 页面2：候选书生成页

### 4.1 页面作用

让 AI 负责收集候选书，而不是让人手工找书。

这是 001号原则在产品中的体现：

> AI做苦活，人做判断。

### 4.2 页面区块

| 区块 | 内容 |
| --- | --- |
| 本轮目标 | 说明本轮希望生成多少本候选书 |
| 样本结构 | 文学、文史哲、社科、艺术、反向样本比例 |
| 候选来源 | 出版社新书目录、豆瓣新书、当当/京东新书榜、过往常进出版社等 |
| 补充要求 | 本月特别想关注或排除的方向 |
| 生成动作 | 点击按钮让 AI 生成候选池 |

### 4.3 核心按钮

| 按钮 | 作用 |
| --- | --- |
| 生成候选书 | AI开始收集并生成候选池 |
| 重新生成 | 候选池明显不符合时重新生成 |
| 保存本轮设置 | 保存本轮样本结构和来源设置 |

### 4.4 必要字段

| 字段 | 说明 |
| --- | --- |
| 候选书数量 | 默认 20 本 |
| 文学比例 | 例如：30%-40% |
| 文史哲比例 | 例如：20%-25% |
| 社科/非虚构比例 | 例如：20%-25% |
| 艺术/跨学科比例 | 例如：10%-15% |
| 反向样本数量 | 默认 1-2 本 |
| 优先来源 | 多选 |
| 本月特别主题 | 可选 |
| 本月排除方向 | 可选 |

### 4.5 AI输出

AI生成：

- 书名。
- 作者。
- 出版社。
- 出版时间。
- 类别。
- 简介。
- 是否近3个月新书。
- 信息是否完整。
- 来源说明。

### 4.6 第一版不做

- 不做自动爬虫配置。
- 不做平台账号绑定。
- 不做自动下单。
- 不做自动库存同步。

## 5. 页面3：AI初筛结果页

### 5.1 页面作用

展示 AI 对候选书的初筛结果。

用户在这里看：

- 哪些是 A 类重点推荐。
- 哪些是 B 类可以推荐。
- 哪些是 C 类观察。
- 哪些是 D 类不推荐。
- AI为什么这样判断。

### 5.2 页面区块

| 区块 | 内容 |
| --- | --- |
| 分级汇总 | A/B/C/D 各有多少本 |
| 候选书列表 | 所有候选书按等级排列 |
| 单本书详情 | 点击某本书后显示AI理由与风险 |
| 筛选器 | 按 A/B/C/D、类别、出版社筛选 |
| 风险提醒 | 显示需要人工确认的信息 |

### 5.3 核心按钮

| 按钮 | 作用 |
| --- | --- |
| 查看A类 | 只看重点推荐 |
| 查看B类 | 只看可以推荐 |
| 查看C类 | 只看观察样本 |
| 查看D类 | 只看不推荐样本 |
| 进入人工复核 | 进入复核页 |

### 5.4 必要字段

| 字段 | 说明 |
| --- | --- |
| 书名 | 候选书名称 |
| 作者 | 作者 |
| 出版社 | 出版机构 |
| 出版时间 | 出版日期或计划时间 |
| 类别 | 文学/社科/哲学等 |
| AI推荐等级 | A/B/C/D |
| 是否进入候选 | 是/否/观察 |
| 推荐理由 | AI解释 |
| 风险提醒 | 库存、版本、定价、供货等 |
| 适合书架/主题 | 陈列建议 |

### 5.5 第一版不做

- 不做复杂图表。
- 不做销售预测。
- 不做读者画像匹配。
- 不做社交分享。

## 6. 页面4：人工复核页

### 6.1 页面作用

让人保留最终判断权。

AI给出建议，但不替代玄石或选书负责人。

### 6.2 页面区块

| 区块 | 内容 |
| --- | --- |
| 待复核列表 | 按 AI 等级排列的候选书 |
| 单本复核卡片 | 展示书目信息、AI理由、风险提醒 |
| 人工判断区 | 同意 / 修改 / 不接受 |
| 人工备注区 | 记录人工判断理由 |
| 分歧记录区 | AI与人工判断不同的地方 |

### 6.3 核心按钮

| 按钮 | 作用 |
| --- | --- |
| 同意 | 认可 AI 判断 |
| 修改 | 部分认可，但调整等级或理由 |
| 不接受 | 否定 AI 判断 |
| 加入最终清单 | 确认进入候选清单 |
| 移出候选清单 | 不进入最终候选 |
| 下一本 | 继续复核下一本 |

### 6.4 必要字段

| 字段 | 说明 |
| --- | --- |
| 人工最终判断 | 同意 / 修改 / 不接受 |
| 人工修改等级 | 如从 B 改为 A |
| 人工理由 | 简短说明 |
| AI是否准确 | 准确 / 部分准确 / 不准确 |
| 是否进入最终候选 | 是 / 否 |
| 是否产生新规则 | 是 / 否 |

### 6.5 第一版不做

- 不做多人审批。
- 不做评论系统。
- 不做复杂权限。
- 不做采购付款流程。

## 7. 页面5：最终清单与规则沉淀页

### 7.1 页面作用

把本轮选书结果变成可执行结果，并把经验沉淀成规则。

### 7.2 页面区块

| 区块 | 内容 |
| --- | --- |
| 最终候选清单 | 本轮最终进入候选的书 |
| 分级统计 | A/B/C/D数量、进入候选数量 |
| 准确率统计 | AI判断准确率 |
| 常见错误 | AI本轮出错或分歧点 |
| 新增规则建议 | AI根据人工反馈提出的新规则 |
| 导出区 | 导出 Markdown / 表格 |

### 7.3 核心按钮

| 按钮 | 作用 |
| --- | --- |
| 生成最终候选清单 | 汇总复核结果 |
| 生成新增规则 | 根据分歧生成规则建议 |
| 批准规则 | 人确认规则进入规则库 |
| 暂不采用规则 | 不保存该规则 |
| 导出清单 | 导出给采购或内部使用 |
| 开启下一轮 | 进入下一月/下一轮选书 |

### 7.4 必要字段

| 字段 | 说明 |
| --- | --- |
| 最终入选数量 | 最终候选书数量 |
| A类数量 | A类书数量 |
| B类数量 | B类书数量 |
| C类数量 | C类书数量 |
| D类数量 | D类书数量 |
| AI准确率 | 人工标记为准确的比例 |
| 新增规则 | 本轮新增或修改规则 |
| 下轮重点 | 下一轮需要观察的问题 |

### 7.5 第一版不做

- 不做复杂BI报表。
- 不做销售转化分析。
- 不做会员推荐。
- 不做库存系统深度集成。

## 8. 用户完整路径

```text
用户进入 AI选书官首页
↓
点击“开始本月选书”
↓
设置候选书数量、样本结构和来源
↓
点击“生成候选书”
↓
AI生成20本候选书
↓
AI完成A/B/C/D评级、理由和风险提醒
↓
用户进入人工复核页
↓
对每本书点击：同意 / 修改 / 不接受
↓
确认最终候选清单
↓
AI总结准确率、错误和新增规则
↓
用户批准规则
↓
导出本月候选书清单
```

## 12. 第一版不做的页面和功能

第一版坚决不做：

- 登录注册复杂体系。
- 复杂会员中心。
- 复杂库存管理。
- 自动采购。
- 自动同步供应商。
- 销售预测。
- 多人协作审批。
- 社区。
- 模板市场。
- 积分系统。
- 内容发布平台。

原因：

第一版只验证一件事：

> AI能否承担选书前置工作，并让人用最短路径完成最终判断。

## 13. 页面设计风格建议

第一版风格应该：

- 极简。
- 像工作台，不像营销页。
- 文字清楚。
- 按钮少。
- 路径短。
- 不炫技。
- 不使用复杂动画。

推荐气质：

```text
安静
克制
专业
有书店感
有判断感
```
