# AI选书官低保真线框图说明 v0.1

> 所属产品：FREETEXT Bookstore OS  
> 所属模块：AI选书官  
> 当前阶段：低保真原型，不写代码  
> 上游文档：AI_BOOK_SELECTOR_WORKFLOW_v0.1.md、AI_BOOK_SELECTOR_PAGE_STRUCTURE_v0.1.md  
> 核心原则：AI做苦活，人做判断

## 1. 本文档目标

本文档用低保真方式描述 AI选书官第一版 5 个页面的布局。

低保真线框图不是视觉设计稿，不讨论颜色、字体、动效和品牌风格，只回答：

- 页面上有什么。
- 信息怎么排布。
- 用户点哪里。
- AI结果在哪里展示。
- 人工判断在哪里完成。

## 2. 设计总原则

第一版只保留一条最短路径：

```text
开始选书
↓
AI生成候选
↓
AI初筛评级
↓
人工复核
↓
最终清单与规则沉淀
```

页面气质：

```text
安静、克制、像工作台、不像营销页
```

第一版不追求漂亮，先追求能跑通。

## 3. 页面1：首页 / 本月选书入口

### 3.1 页面目的

让用户一进来就知道当前状态，并点击“开始本月选书”。

### 3.2 页面草图

```text
┌──────────────────────────────────────────────┐
│ AI选书官                                     │
│ 副标题：AI做苦活，人做判断                   │
├──────────────────────────────────────────────┤
│ 本月状态                                     │
│ 当前月份：2026年6月                          │
│ 当前状态：未开始 / 待生成 / 待复核 / 已完成  │
│ 当前规则版本：v0.1                           │
├──────────────────────────────────────────────┤
│ 上次选书结果                                 │
│ 第1轮：20本，判断一致                        │
│ 第2轮：20本，判断一致                        │
│ 最新规则：文学样本比例提高到30%-40%          │
├──────────────────────────────────────────────┤
│ [开始本月选书]      [查看上次结果]            │
└──────────────────────────────────────────────┘
```

### 3.3 用户动作

- 点击“开始本月选书”。
- 进入候选书生成页。

### 3.4 页面要点

- 一个主按钮。
- 不放复杂菜单。
- 不做营销大图。
- 不让用户思考下一步在哪里。

## 4. 页面2：候选书生成页

### 4.1 页面目的

让 AI 根据规则生成候选书，不让用户手工找书。

### 4.2 页面草图

```text
┌──────────────────────────────────────────────┐
│ 候选书生成                                   │
│ 说明：AI将根据自由文本规则生成本轮候选池      │
├──────────────────────────────────────────────┤
│ 本轮目标                                     │
│ 候选书数量：[20] 本                          │
│ 希望进入候选清单：[5-8] 本                   │
├──────────────────────────────────────────────┤
│ 样本结构                                     │
│ 文学/文学研究/高质量小说：[30%-40%]          │
│ 文史哲/思想/文化史：[20%-25%]                │
│ 社科/非虚构/社会观察：[20%-25%]              │
│ 艺术/设计/跨学科：[10%-15%]                  │
│ 反向样本：[1-2] 本                           │
├──────────────────────────────────────────────┤
│ 候选来源                                     │
│ [x] 出版社新书目录                           │
│ [x] 豆瓣新书速递                             │
│ [x] 当当/京东新书榜                          │
│ [x] 自由文本过去常进出版社                   │
│ [x] AI认为值得观察的新书                     │
├──────────────────────────────────────────────┤
│ 本月特别关注：                               │
│ [ 文学、思想、真实中国、AI与技术社会 ]        │
│ 本月特别排除：                               │
│ [ 低质鸡汤、纯流量畅销、应试工具书 ]          │
├──────────────────────────────────────────────┤
│ [生成候选书]      [保存本轮设置]              │
└──────────────────────────────────────────────┘
```

### 4.3 用户动作

- 默认不用改设置。
- 直接点击“生成候选书”。

### 4.4 AI动作

AI生成候选池，输出：

- 书名。
- 作者。
- 出版社。
- 出版时间。
- 类别。
- 简介。
- 来源。
- 信息完整度。

### 4.5 页面要点

- 默认值优先，用户不要填太多。
- 可以让用户微调样本结构。
- 不能把收集书单的苦活交给用户。

```text
├─────────────────────────────────────────────────────────┤

├───────────────────────┬─────────────────────────────────┤

│                       │                                 │
│ A  永结无情游         │ 书名：永结无情游                │
│ A  要有光             │ 作者：周嘉宁                    │
│ A  士变               │ 出版社：人民文学出版社          │
│ A  先秦人的日常时光   │ 类别：文学/长篇小说             │
│ B  绿色的火焰         │                                 │
│ B  地中海文明共同体   │ AI推荐等级：A                   │
│ C  Land               │ 推荐理由：符合自由文本文学气质  │
│ C  Vigil              │ 风险提醒：需确认出版与库存      │

│                       │                                 │
│                       │ [进入人工复核]                  │
```

### 5.3 用户动作

- 快速查看 A/B/C/D。
- 点击某本书看理由。
- 点击“进入人工复核”。

### 5.4 页面要点

- 左边列表，右边详情。
- 不用复杂图表。
- 评级、理由、风险必须在同屏可见。

## 6. 页面4：人工复核页

### 6.1 页面目的

让人保留最终判断权。

AI不替人决定采购。

### 6.2 页面草图

```text
┌─────────────────────────────────────────────────────────┐
│ 人工复核                                                 │
│ 进度：第 1 / 20 本                                      │
├─────────────────────────────────────────────────────────┤
│ 当前书目                                                 │
│ 书名：永结无情游                                        │
│ 作者：周嘉宁                                            │
│ 出版社：人民文学出版社                                  │
│ 类别：文学/长篇小说                                     │
├─────────────────────────────────────────────────────────┤
│ AI判断                                                   │
│ 推荐等级：A                                             │
│ 是否进入候选：是                                        │
│ 推荐理由：符合自由文本当代文学气质                      │
│ 风险提醒：需确认出版时间、库存、定价                    │
├─────────────────────────────────────────────────────────┤
│ 人工判断                                                 │
│ [同意]   [修改]   [不接受]                              │
│ 是否进入最终候选： [是] [否]                            │
│ AI是否准确： [准确] [部分准确] [不准确]                  │
│ 人工备注：                                              │
│ ┌───────────────────────────────────────────────────┐   │
│ │                                                   │   │
│ └───────────────────────────────────────────────────┘   │
├─────────────────────────────────────────────────────────┤
│ [上一本]        [保存并下一本]        [完成复核]          │
└─────────────────────────────────────────────────────────┘
```

### 6.3 用户动作

每本书只做最小判断：

- 同意。
- 修改。
- 不接受。

并标记 AI 是否准确。

### 6.4 页面要点

- 每次只看一本书。
- 不让用户被20本同时淹没。
- 复核动作必须非常快。

- 结果必须可执行。
- 规则必须沉淀。
- 不做复杂报表。

## 8. 页面之间的跳转关系

```text
首页
  ↓ 点击“开始本月选书”
候选书生成页
  ↓ 点击“生成候选书”
AI初筛结果页
  ↓ 点击“进入人工复核”

  ↓ 点击“完成复核”
最终清单与规则沉淀页
  ↓ 点击“开启下一轮”
回到首页 / 新一轮候选生成
```

## 10. 第一版视觉布局原则

### 10.1 统一布局

每页顶部保持一致：

```text
AI选书官 / 当前页面名 / 当前状态
```

### 10.2 信息密度

- 首页信息最少。
- 生成页以设置为主。
- 初筛页以列表+详情为主。
- 复核页每次只聚焦一本书。
- 总结页以结果和规则为主。

### 10.3 交互节奏

```text
少填、多看、快判断
```

## 11. 第一版不画的东西

低保真阶段不画：

- 品牌视觉。
- 颜色系统。
- 插图。
- 动效。
- 登录注册。
- 会员中心。
- 销售看板。
- 库存系统。
- 采购系统。
- 多人协作。

AI选书官第一版原型可以用 5 个页面完成。

```text

↓
```
