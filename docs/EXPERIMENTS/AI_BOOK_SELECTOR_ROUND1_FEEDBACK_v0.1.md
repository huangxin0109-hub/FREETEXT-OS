## 4. 需要新增的规则

### 规则 001：候选书收集不应由玄石完成

AI负责候选书收集、初筛、解释和整理。玄石只负责最终复核。

### 规则 002：第2轮必须提高文学样本比例

第2轮候选池中文学、文学传记、文学研究、高质量小说、诗歌/戏剧相关图书应占约 30%-40%。

### 规则 003：第2轮重点验证文学判断能力

第1轮已经初步验证 AI 对文史哲、社科、非虚构的判断能力。第2轮应重点测试 AI 是否能识别自由文本的文学气质，而不是只会判断思想类和社科类图书。

## 5. 第2轮建议

下一步进入第2轮测试，由 AI 继续负责收集 20 本候选书，但样本结构调整为：

| 类别 | 建议数量 |
| --- | --- |
| 文学/文学传记/文学研究/高质量小说 | 7-8 本 |
| 哲学/思想/文化史 | 4-5 本 |
| 社科/非虚构/社会观察 | 4-5 本 |
| 艺术/设计/跨学科 | 2-3 本 |
| 明显不适合自由文本的对照样本 | 2 本 |

## 6. 当前结论

AI选书官不是一个幻想模块，它已经出现了第一个强信号：

AI可以承担自由文本选书流程中的前置收集、初筛、解释和规则沉淀工作。玄石不需要亲自收集样本，只需要做最终判断。

第1轮最重要的结果不是“选出了哪几本书”，而是验证了工作模式：

AI做苦活，人做判断。

这正是001号原则在真实业务中的一次有效落地。
