# FREETEXT OS 0.1

FREETEXT OS 是自由文本下一阶段的产品操作系统。它不是一个普通文档库，而是把我们长期对话、经营经验、产品判断、AI策略和创业原则整理成可被 ChatGPT、Codex、Claude Code、Cursor 继续读取和执行的基础知识库。

## 当前阶段

FREETEXT4.0 尚未正式进入开发。当前最重要任务不是写代码，而是完成产品定义、PRD、技术路径和 Agent 协作规则。
